# Bill Manager API

The Bill Manager API allows businesses to integrate their billing, invoicing, and payment reconciliation directly with M-Pesa.

## Key Features
- Send customized invoice SMS reminders directly to customers.
- Update payment billing status programmatically.
- Reconcile payments in bulk.

## API Endpoint Examples
- **Opt-In:** `POST https://sandbox.safaricom.co.ke/v1/billmanager-invoice/optin`
- **Create Invoice:** `POST https://sandbox.safaricom.co.ke/v1/billmanager-invoice/create`
- **Reconciliation:** `POST https://sandbox.safaricom.co.ke/v1/billmanager-invoice/reconcile`
