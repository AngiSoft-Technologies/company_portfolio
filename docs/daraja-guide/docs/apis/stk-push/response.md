# M-Pesa Express (STK Push) - Response

When you execute an STK request, Safaricom immediately returns a synchronous acknowledgement. This informs you whether Safaricom has successfully processed your query and dispatched the prompt to the user's phone.

## Synchronous Response

### Success Example (`HTTP 200 OK`)
```json
{
 "MerchantRequestID": "29115-34626-1",
 "CheckoutRequestID": "ws_CO_191220191020363925",
 "ResponseCode": "0",
 "ResponseDescription": "Success. Request accepted for processing",
 "CustomerMessage": "Success. Request accepted for processing"
}
```

### Error Example (`HTTP 400 Bad Request`)
```json
{
 "requestId": "12345-67890-1",
 "errorCode": "400.002.02",
 "errorMessage": "Invalid CallBackURL value"
}
```

---

## Fields Explained
- **MerchantRequestID:** Unique ID generated by Safaricom to track the original transaction.
- **CheckoutRequestID:** The session identifier for the STK prompt. This is what connects the synchronous response with the incoming asynchronous callback. Save this in your database!
- **ResponseCode:** Returns `0` if successful, which means the prompt was pushed to the phone.
