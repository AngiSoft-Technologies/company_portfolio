## Notes

- **Permission resolution:** route guards use `requireAccess(permission, fallbackRoles)`; an explicit DENY is checked *before* the role fallback (`backend/src/shared/middleware/roles.ts:41-62`) and before the SUPER_ADMIN wildcard (`effectivePermissions.ts:95-110`).
- **Public content rule:** all public pages read `/v1/*`; business content must not be hardcoded in components (`AGENTS.md`).
- **Admin UIs:** every backend domain has a screen, including Phase 7 Finance/Communications (`/finance*`, `/communications*`, `/webhook-inbox`) and AI Workforce (`/agents`, `/boardroom`).
- **Structural gaps remaining:** none in the content matrix; the open items are operational (permission seed, provider provisioning, integration DB, Lighthouse/security audits) — see `PRODUCTION_READINESS.md`.
- **Snapshot caveat:** the registry and route set changed during this verification turn; re-run greps before release signoff.
