# 🌐 Internationalisation (i18n)

> **🛠 OPERATIONAL** — Current reference for UI locales in the public site and admin app.

## Supported locales

Both Vite apps share `@angisoft/i18n` and expose **21 selectable UI locales**:

| Code | Locale | Code | Locale | Code | Locale |
|------|--------|------|--------|------|--------|
| `en` | English (default/fallback) | `sw` | Kiswahili | `fr` | Français |
| `es` | Español | `de` | Deutsch | `pt` | Português |
| `it` | Italiano | `nl` | Nederlands | `ru` | Русский |
| `uk` | Українська | `pl` | Polski | `tr` | Türkçe |
| `ar` | العربية (RTL) | `fa` | فارسی (RTL) | `hi` | हिन्दी |
| `ja` | 日本語 | `ko` | 한국어 | `zh` | 中文 |
| `id` | Bahasa Indonesia | `vi` | Tiếng Việt | `th` | ไทย |

Registered in `packages/i18n/src/locales.ts`; dictionaries live in
`packages/i18n/src/dictionaries/`. English (`en.ts`) is the canonical source
with **115 keys**; every other locale ships a complete 115-key dictionary, and
`translate()` still falls back per key to English for unknown locales or future
keys added before a translation lands.

## Runtime behaviour

- `LanguageProvider` (mounted in both `src/main.tsx` files) persists the choice
  under `angisoft-language`, mirrors it to `<html lang/dir>`, and syncs other
  tabs through the `storage` event.
- `LanguageSwitcher` is mounted in the public site header and the admin shell.
  Arabic and Persian set `dir: 'rtl'`; all others are LTR.
- `resolveLocale()` maps BCP-47 tags to the closest supported locale
  (`pt-BR` → `pt`, `sw-KE` → `sw`, `zh-Hans` → `zh`); unknown tags fall back to
  English. `detectLocale()` uses the browser/OS languages when no stored choice
  exists.
- Dates, numbers and currency display use `Intl`; no server-side translation or
  locale routing is involved. Listed prices and payments keep their source
  currency (KES by default) — the locale switcher never performs FX.

## Adding or changing a translation

1. Add the canonical English key to `dictionaries/en.ts`.
2. Add the same key to every locale dictionary (or rely on the English fallback
   temporarily).
3. Update `LOCALES` and `dictionaries/index.ts` for a new language.
4. Run `pnpm --filter angisoft-web test -- src/lib/i18n.test.ts`: the contract
   suite asserts locale registration, RTL flags, complete dictionaries,
   BCP-47 resolution, fallback and interpolation.

Translations in this initial global expansion were generated programmatically
and are functionally complete; native-speaker review is recommended before
marketing copy is localised beyond the shared UI strings.
